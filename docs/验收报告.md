## 三、典型用法

```bash
CLI=~/.hermes/skills/bidai-cloud/scripts/bidai.py

# 1. 搜资源
python3 $CLI search "高三数学模拟卷" --size 20

# 2. 看这个分享里有什么（文件夹继续 --parent 下钻）
python3 $CLI share-files 8911

# 3. 一条命令搞定：转存 → 拿签名直链 → 下载 → md5 校验 → 清掉转存副本
python3 $CLI download-share 8911 572066384 -o ~/试卷.pdf --cleanup

# 4. 管理自己网盘
python3 $CLI ls                      # 看根目录（根 parent=-1）
python3 $CLI mkdir "高三一轮"
python3 $CLI upload ~/xxx.pdf --parent <目录id>
python3 $CLI rm <id>                 # 进回收站；--hard 永久删
```

输出默认 JSON（便于我解析），错误走 stderr、退出码非 0。

## 四、逆向到的关键机制

- 网关 `https://api.gaojiua.com/release`，**必须带** `AppFingerprint: bidai` + `PlatformName: H5`
- 登录：`POST /api/user/token/code/`（发码）→ `POST /api/user/token/`（`password` 字段填验证码）→ `access` 十年有效
- 从主包提取到 **92 个 API 端点**（方法+路径+参数），52 个"只差参数"的端点靠 422 报错反推出完整字段名
- **根目录 id = `-1`**（不是 0）
- **别人的文件不能直接下载**：`pre-download` 只认自己的文件 → 必须先 `share/import` 转存
- 裸 `file_url` 下载会 403（腾讯云 COS 签名）→ 签名直链从 `GET /api/cloud/file/pre-download/?file_id=&file_url=` 拿
- **上传**：`pre-create` 拿 COS 临时凭证 → q-sign 签名直传 → `complete-upload`；同 md5 自动秒传
  - q-sign 的坑：`StringToSign` **末尾多个换行**，写错就 403（是照着 COS 报错里回显的 FormatString 逐字节比对才修好的）
- 三个"假失败"：`share-create` / `share-delete` / `star` 服务端返回 500 但操作实际生效，判定成功要复核列表

## 六、没做的部分（有意跳过）

- **打印下单、收货地址、商城订单、支付**：有真实资金/个人信息副作用，不纳入自动化
- **admin 后台端点**：403「没有权限」，需要平台员工账号
- **整文件夹上传**：只实现单文件（文件夹上传涉及递归遍历，需要时可加）
- `upvote`/`followUser`：会产生他人可见的社交动作，可用但未纳入自测

## 七、安全

- token 存 `~/.bidai_token`（权限 600），**不写进 SKILL.md、不出现在聊天记录**
- 手机号存 `~/.bidai_config.json`（600），报告里只显示后 4 位
- 删除类操作只对自己新建的测试项执行过，你的原有 16 项文件一个没动
